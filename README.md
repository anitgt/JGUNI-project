# JG University Modern Landing Page

A modernized, responsive, and highly engaging landing page for JG University. Built with Next.js and Tailwind CSS, this project aims to provide a superior user experience, showcasing the university's programs, features, and values with a premium aesthetic.

## 🚀 Live Demo

Check out the live deployment here: **[https://jguni-project.vercel.app/](https://jguni-project.vercel.app/)**

## ✨ Features

- **Modern & Premium UI:** Designed with a vibrant, clean, and professional aesthetic using Tailwind CSS.
- **Responsive Design:** Fully responsive layout that looks great on mobile, tablet, and desktop devices.
- **Dynamic Animations:** Smooth micro-animations and transitions powered by Framer Motion.
- **Key Sections:**
  - Engaging Hero Section
  - Responsive Navbar
  - About Section
  - Features & Programs Overview
  - Testimonials Display
  - High-conversion Call-to-Action (CTA)
  - Comprehensive Footer
- **SEO Optimized:** Uses Next.js built-in SEO capabilities, semantic HTML, and proper heading structures.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Language:** TypeScript
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 💻 Getting Started

To run this project locally, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed on your machine.

### Installation

1. Clone the repository (if you haven't already).
2. Navigate to the project directory:
   ```bash
   cd "JGUNI project"
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

### Running the Development Server

Start the Next.js development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. You can start editing the page by modifying `src/app/page.tsx`. The page auto-updates as you edit the file.

## 📁 Project Structure

- `src/app/`: Contains the main application pages and layouts (Next.js App Router).
- `src/components/`: Reusable React components (Navbar, Hero, About, Features, Testimonials, CTA, Footer).
- `public/`: Static assets such as images and fonts.
